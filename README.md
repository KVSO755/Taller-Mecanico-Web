# TallerApp

Aplicación web para la gestión de un taller mecánico.

## Stack

Vite + React (JavaScript), Tailwind CSS v4, React Router v7, Supabase.

## Puesta en marcha

```bash
npm install
cp .env.example .env.local   # completa VITE_SUPABASE_URL y VITE_SUPABASE_ANON_KEY
npm run dev
```

(Se completará más adelante.)
